# Thread 配图与英文 ALT

输出 Thread 时读取。每个 Post 都需要相关图片及逐图英文 ALT，包括首帖、背景帖和收尾帖；来源 Comment 不要求配图。用户本次明确要求纯文字时才覆盖这条要求。

## 选图与来源

先建立“本帖信息点 → 图片 → 图片能支持什么”的对应关系，再交付图文稿。不要先写完正文，再随意塞一张装饰图。

- 优先选指定原文中的原图、图表、实测截图或用户提供的素材。核对图片所属回答和作者，不混入推荐内容、其他答主的结果、广告或页面插件信息。
- 首帖选能直接体现核心发现或结果的图；正文仍须独立说明亮点、中心思想与结论。后续图片各自支撑所在帖的方法、结果、对比或限制，不能把全部图片集中堆在文末。
- 每帖通常 1–4 张；只放必要图片，明确上传顺序。图中左右、上下、颜色、图例、单位、实验条件和模型版本都要核对。相关性来自可见证据，不能靠 ALT 强行建立。
- 同一张图确实同时支持两个信息点时可复用，说明其对应含义；不要为凑数在每帖重复一张图。应根据原文的信息结构调整分帖，不根据图片数量机械切正文。
- 保留会影响解释的图注、坐标轴、图例和署名。不裁掉负面结果或用局部放大伪装整体质量。允许清晰说明的裁切、翻译标注或排版整理，但不得改变实测结果；优先保留未改动原图。

## 没有合适原图时

可以依据已核验的原文文字、数据或用户提供的背景制作简洁的英文文字卡、数据卡或流程示意图。图内标明 `Editorial graphic based on the source`；逐图来源记录说明对应来源，ALT 说明它是整理图。这仍然是来源信息的呈现，不是补充研究或编造证据。

- 文字、数值、箭头所表达的关系和结论都必须在来源中成立。不要添加原文没有的收益、排名、因果、成本或未来预测。
- 只有定性描述时，使用文字卡，不编造比例、坐标、柱形高度或示意数据。原文没有结论时，可呈现尚未解决的问题，不替作者下结论。
- 不制作看似模型实际生成的样图、运行截图或实验曲线。不得用 AI 生成的效果图冒充原文实测成果。
- 背景帖可用来源明确的测试条件卡；收尾帖可用来源支持的结论与限制卡。不得因为这些帖缺原图而自行跳过配图或 ALT。

## 获取与保存

1. 只使用已从指定原文、用户素材或其中明确引用的相关来源观察到的图片地址，不猜 URL。查看每张拟用图片；链接或文件存在不等于图像内容已核对。
2. 优先保存可用原始尺寸文件，核对实际格式、尺寸与内容。文件扩展名须与内容相符，不能把 HTML 错误页当图片。优先使用能实际展示或下载源图的工具。
   SVG 可用于可移植示例或制作过程；实际发布素材应渲染为当前平台支持的图片格式（如 PNG 或 JPEG），并检查渲染效果。
3. 保存到当前用户指定的产出目录，按 Post 和上传顺序命名；在对应 Post 下嵌入可打开的图片，并记录来源。交付时使用环境要求的路径格式；本地文件优先使用绝对路径。
4. 原图不可获取时，尝试同一原文中实际可用的读取方式；不要持续重试无变化的失败请求。可用原文截图时只截相关图像区域，排除账号信息和页面插件。若改为整理图，明确标注。
5. 无法落盘但可展示远程原图时，可以嵌入实际可打开的原图 URL，说明依赖联网。没有实际可用图片时，列明缺项和具体原因，不用占位符、空链接或“建议配图”冒充完成；原文可读部分仍可先整理。

## 英文 ALT

每张图都有独立、非空、可复制的英文 ALT，与图片一一对应。ALT 用于描述图像，不是营销文案，也不替代帖子正文。

- 描述图中可见的主体、结构和与本帖有关的信息；比较图写清左右或上下分别是什么，原图与模型输出不能互换。
- 图表描述必要的轴、单位、系列或可见趋势；关键数值只有清晰可读且已核对时才写。不要把帖子里有、图中没有的测试时间或成本强塞进 ALT。
- 区分实测截图、示意图、原图与整理图。不能把模型自评写成第三方验证，把估算尺寸写成官方测量值。
- 保留必要的不确定性。文字卡的 ALT 包含卡片中的关键英文文字；中文原图保留时，用英文解释与本帖有关的可见信息。
- 默认用 1–3 个自然英文句子写清楚；复杂图表按实际需要增加信息，不只写 `chart` 或重复帖子的标题，不猜测看不清的内容。

## 交付顺序

下面是结构模板，尖括号占位内容须在真实交付时全部替换为实际正文、可用图片、来源与英文 ALT。每帖的图片编号从 1 开始；多图按上传顺序递增。Comment 只有来源正文，不加配图。

````markdown
Post 1

```markdown
<首帖英文正文：核心发现、中心思想、结论和必要限定>
```

Image 1
![<简短英文图片描述>](<实际图片路径或已核验原图 URL>)

Image source 1: <原文链接、用户素材文件路径，或注明由哪些来源内容整理而成>

ALT 1
```text
<描述这张图片实际内容的英文 ALT>
```

Post 2

```markdown
<下一信息单元的英文正文>
```

Image 1
![<简短英文图片描述>](<实际图片路径或已核验原图 URL>)

Image source 1: <这张图的来源记录>

ALT 1
```text
<这张图的英文 ALT>
```

Comment

```markdown
<原文链接与必要参考链接>
```
````

正文代码块里不放图片链接、中文编辑说明或 ALT。用户复制正文后仍需另行上传图片，并把每条 ALT 填入对应图片描述；不得声称粘贴 Markdown 会自动完成这些操作。

## 验收

先核图文语义，再核交付完整性：每帖是否有真实可用图片；每张是否有匹配的英文 ALT、可追溯来源和上传顺序；整理图是否明确标注；首帖是否在不依赖配图的情况下完整表达中心结论。格式脚本只能检查结构、配对和本地文件存在性，不能替代实际看图和事实审校。
